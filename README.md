# Site web CAP Désamiantage

Interface React + TypeScript + Vite du site Cap Désamiantage.

## Voir le site avec Vercel

Importer ce dépôt dans Vercel. La configuration fournie utilise `npm run build` et publie le dossier `dist`.

Cette version de présentation affiche le hero, la timeline verticale « Comment ça marche », les types de chantiers et le formulaire. Le traitement serveur du formulaire nécessite séparément l’API et la base de données du projet complet.
